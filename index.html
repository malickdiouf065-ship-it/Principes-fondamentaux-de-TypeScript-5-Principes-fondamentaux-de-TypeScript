TypeScript Vehicle & Car

Exercice pratique : interfaces, classes, constructeur et méthodes en TypeScript.

Réalisé par : Serigne Malick Tall Diouf

📚 1. Présentation du devoir

L'objectif de cet exercice est de créer une interface Vehicle, puis une classe Car qui implémente cette interface. Nous allons ensuite créer une voiture et démarrer son moteur.

💻 2. Interface Vehicle

Une interface définit les propriétés et les méthodes qu'une classe doit respecter. 

interface Vehicle {
    make: string;
    model: string;
    year: number;

    start(): void;
}

⚙️ 3. Classe Car

La classe Car implémente l'interface Vehicle. Son constructeur initialise les trois propriétés et sa méthode start() affiche un message. 

class Car implements Vehicle {

    make: string;
    model: string;
    year: number;

    constructor(
        make: string,
        model: string,
        year: number
    ) {
        this.make = make;
        this.model = model;
        this.year = year;
    }

    start(): void {
        console.log("Moteur de la voiture démarré");
    }
}

🚗 4. Création d'une voiture

Nous créons une instance de Car avec la marque Toyota, le modèle Corolla et l'année 2024. 

const myCar = new Car(
    "Toyota",
    "Corolla",
    2024
);

myCar.start();

🔄 6. Code JavaScript compilé

Voici la version JavaScript équivalente au code TypeScript. Elle permet d'exécuter la démonstration directement dans le navigateur. 

class Car {
    constructor(make, model, year) {
        this.make = make;
        this.model = model;
        this.year = year;
    }

    start() {
        console.log(
            "Moteur de la voiture démarré"
        );
    }
}

const myCar = new Car(
    "Toyota",
    "Corolla",
    2024
);

myCar.start();
